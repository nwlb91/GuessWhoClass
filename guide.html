Find anyone in 4 questions

There are 16 faces. A yes/no question that splits the faces still standing exactly in half means every answer leaves half as many: 16 → 8 → 4 → 2 → 1. Four halvings, because 2 × 2 × 2 × 2 = 16. That’s binary search. The faces were designed so the halving questions are easy to remember.

“Is it a man?”8 men, 8 women
If it’s a man, ask in order:
  1. Hat?
  2. Glasses?
  3. Beard?

Read his face from the top down: hat, glasses, beard.

If it’s a woman, ask in order:
  1. Earrings?
  2. Necklace?
  3. Bow in her hair?

Earrings and a necklace, then tie it up with a bow, like wrapping a present.

Each of the 8 men has a different mix of hat / glasses / beard, and each of the 8 women has a different mix of earrings / necklace / bow. So those three questions halve the group in any order. The order above is just easy to remember.

Why it’s not obvious: the decoys

To stop students spotting the pattern straight away, some of the “key” features also turn up where they don’t help. They make tempting first questions that almost split the board in half, but not quite.

Only “Is it a man?” (or “Is it a woman?”) splits all 16 into 8 and 8. With strategy hints turned on, the game shows each question’s split, like 8|8 or 7|9.

Lesson ideas

  1. Play first, explain later. Let students play a couple of rounds (or practice solo) and record how many questions they needed before they knew the answer.
  2. Find the best first question. Ask: “Which question flips down the most faces whatever the answer is?” Compare “Is it Grace?” (flips down 1 face or 15) with “Hat?” (7 or 9) and “Man?” (8 either way).
  3. Play with hints. Turn on Strategy hints in the lobby. The game shows how every question would split the faces still standing and stars the best one.
  4. Name the pattern. 16 → 8 → 4 → 2 → 1. How many questions for 32 faces? 64? 1,000? (5, 6, and 10, because 2¹⁰ = 1,024.)
  5. Connect it. Looking up a word in a dictionary, the “higher or lower” number game, and finding a page in a book all work the same way.

Running a game

  1. Click Host a game. You get a 4-character code and a QR code. Put it on the projector.
  2. The student scans the QR code (or opens this site and types the code), enters their name, and joins.
  3. You both pick a mystery person, and the student asks first. Questions from the list are answered automatically. Typed questions are answered by the other player.
  4. For the next student, open the menu (☰) and choose Invite a different student. To run several games at once, open the site in more browser tabs. Each tab hosts its own game with its own code.
  5. Students can also host games for each other. Anyone can click Host a game.

Games connect the two browsers directly (peer-to-peer). Nothing is stored on a server and no accounts are needed. If someone loses connection or refreshes, they reconnect to the same game automatically while the host’s page stays open.
